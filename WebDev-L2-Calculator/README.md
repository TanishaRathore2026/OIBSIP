# NexaCalc 🧮

A modern, responsive calculator built using HTML5, CSS3, and Vanilla JavaScript.

NexaCalc provides a clean and user-friendly interface for performing basic arithmetic calculations with additional features such as calculation history, keyboard support, and theme switching.

## ✨ Features

- Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Modulus
- Numbers from 0–9
- Decimal number support
- Clear (AC) button
- Backspace button
- Division-by-zero error handling
- Operator chaining
- Calculation history
- Clear history option
- Keyboard support
- Light/Dark theme toggle
- Responsive design for mobile and desktop
- Smooth button interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
