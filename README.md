# Dr. A.P.J. Abdul Kalam — Tribute Page

A responsive and visually polished tribute webpage dedicated to Dr. A.P.J. Abdul Kalam, highlighting his life, achievements, journey and inspiring philosophy.

## ✨ Features

- Premium responsive landing page
- Hero section with portrait and introduction
- About section
- Life journey timeline
- Achievements and legacy cards
- Inspirational quote section
- Smooth scrolling
- Scroll reveal animations
- Hover interactions
- Fully responsive design for desktop, tablet and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
